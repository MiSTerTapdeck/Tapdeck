# Security policy

## Reporting a vulnerability

Please do not report security issues in a public GitHub issue.

Use [GitHub private vulnerability reporting](https://github.com/MiSTerTapdeck/Tapdeck/security/advisories/new) for this repository. Include a clear description, affected version, reproduction steps, and any suggested mitigation. Do not include IGDB credentials, MiSTer IP addresses, Wi-Fi details, or game files.

We aim to acknowledge reports within seven days and provide a status update within 30 days.

## Scope

This policy covers the Tapdeck Android app and the helper services supplied in this repository. The app and helpers are intended for a trusted home network. They must not be exposed to the public internet.

MiSTer, Zaparoo, MiSTer Remote, IGDB, Twitch, Android, and third-party game metadata or artwork services are maintained by their respective projects. Report vulnerabilities in those products to their own maintainers.
